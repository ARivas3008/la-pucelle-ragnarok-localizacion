# Piloto de capítulos

Instalar localmente numpy, Pillow y opencv-python. Usar Liberation Serif Bold local (no incluida). Ejecutar desde el repositorio: `python scripts/gfx007_editar_capitulos.py --iso-original ORIGINAL.iso --salida PILOTO.iso --fuente LiberationSerif-Bold.ttf --informe resultado.json`. La herramienta exige todos los hashes observados en el experimento y rechaza divergencias. No subir originales ni candidatos. No es candidata completa ni certificado visual de PPSSPP.
